### デザイン（goodpatch.com/ja/ai を参考にした v3）

- **帯の切り替え：** グレー（入口）→ 白（AirReach）→ 青（Adctor）→ グレー（協業・投資）。背景色で「いまどの事業を読んでいるか」が分かるようにした。
- **大きな英字＋日本語見出し：** 「Two Businesses」「AirReach」「Adctor」を大きく置き、すぐ下に日本語の見出しで意味を伝える。
- **入口カード：** 青（AirReach）と濃紺（Adctor）の2枚。等高線の背景、線画のアイコン、対象者のラベル、「Status」タグ（提供中／研究開発・限定実証）。ホバーで浮き上がり、矢印が動く。
- **AirReachの図：** 楕円の上に「Measure 測る → Improve 直す → Re-measure 再計測」を配置。画面に入ると線が描かれる。スマホでは縦の番号付きリストに切り替え。
- **Adctorの図：** 「情報の流れ」（情報提供者 → Adctor → AI事業者）と「対価の流れ・検証中」（逆の流れ）の2層。逆の流れはオレンジで区別。スマホでは縦に積む。
- **AirReachの使い方：** 3列の一覧（無料診断／Consulting／Tools）と「View Details」。スマホでは縦並び。

## 3. 確認したこと

- **画面幅：** 320 / 390 / 768 / 1440px の4つで、横スクロールなし、事業セクション内のはみ出しなし、事業セクション内のリンク・ボタンはすべて高さ44px以上。
- **リンク：** ページ内リンク（#business #airreach #adctor #usecases #media #news #company #contact ほか）はすべて着地先あり。`#products` はAirReachの使い方に着地。
- **直接リンク：** `index.html#adctor` のように直接開くとオープニングを出さず、その場所から表示する。
- **環境：** JavaScriptなしでも事業紹介は全文読める。動きを減らす設定でも読める。
- **重なり：** 事業紹介が画面にある間は、マスコットと隠しフレームの表示を退避し、本文やボタンにかぶらない。JavaScriptなしのときは、マスコットと隠しフレームを表示しない。
- **図の表示：** 図が画面に入って動きが終わった状態を 1440px と 390px で撮影し、文字と線が重ならないことを確認した。
- **未実施：** フォーム送信・有料登録はテストしていない。

## 4. 残っている確認事項

1. **段階の表記：** Adctorの「研究開発・限定実証」は、現行サイトの「研究開発・PoC相談受付」と表記がそろっていません。どちらに統一するかを決めてください。
2. **Toolsの申込状態：** AirReach Tools（一般向け）を今すぐ申し込めるかを確認してください。確認できれば、使い方3つの中に「すぐ使える／お問い合わせから」を書き添えます。
3. **投資家の窓口：** 投資家向けの問い合わせは、現在は一般のお問い合わせフォームへつないでいます。専用の窓口を作る予定があれば差し替えます。
4. **事例：** 実績のグラフや導入事例は、公開許諾のある事例がそろうまで置いていません。

## 6. 動きの追加（goodpatch.com/ja のホバー・スクロールを参考）

追加ファイル：`gp-motion.css`・`gp-motion.js`（動き）、`hero-geo.js`（ヒーローの背景）。この3つと、`index.html` の読み込み3行を外すと元の動きに戻ります。

| 動き | 内容 |
|---|---|
| 最初のスクロール | PC：ヒーローを画面に固定したまま、背景が中央の丸に集まって白い背景に変わり、そのままステートメントのロゴの丸に重なる。周りに見出し（左）・本文（右）が下から上がってくる。スマホ：ヒーローが丸に縮みながら流れていく |
| ヒーローの背景 | 三角形の幾何学模様。カーソルの近くの面が盛り上がって光り、頂点に小さな光の点。カーソルがないときはゆっくりした波。「動き：OFF」で停止 |
| ステートメント | 1文字ずつ、少し沈んだ位置から色がつく |
| 色の濃いセクションの上端 | Adctor・メディア・お問い合わせ・フッターの上端が山なりのカーブ。スクロールの速さでばねのように弾む |
| カードの視差 | メディア・ニュースのカードが少しずつ違う速さで流れる（PCのみ） |
| ヘッダーのメガメニュー | Business にカーソル（またはキーボードのフォーカス）で、AirReach／Adctor のカードと関連リンクが開く。Escで閉じる |
| ナビの下線 | 左から伸び、右へ抜ける |
| ボタン | 文字が上へ入れ替わり、少し押し込まれる |
| カード | 画像の枠が内側に縮み、中身が少しズーム。見出しが青に |
| 一覧の行 | 背景がふわっと満ち、見出しが右へ動く |

動きの速さは Goodpatch の実測値（色・拡大縮小 0.3秒、画像のズーム 0.6秒）にそろえています。動きを減らす設定では、固定・カーブ・視差・背景の動きはすべて止まります。

### 追加（第3弾）：取締役・メンバー紹介（#members）
